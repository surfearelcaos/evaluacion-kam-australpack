# Evaluación de Perfil — KAM Materiales

Herramienta de evaluación psicolaboral para el proceso de selección del cargo de Key Account Manager — Área de Materiales, Austral Pack S.A.

## Uso

Este repositorio aloja una aplicación web estática de uso interno para el proceso de selección 2026. El acceso al informe de resultados está protegido por contraseña y es de uso exclusivo del equipo de Personas.

## Confidencialidad

El contenido de este repositorio es de uso interno de Austral Pack S.A. Los resultados de las evaluaciones son confidenciales y no deben compartirse fuera del equipo de Personas.
